# Lexos Backlog

## 版本规划

### MVP v0.1：内部任务抢单与客户大屏闭环

目标：跑通从发单、抢单、交付、客户确认到结算的最小业务链路。

### v0.2：任务协作增强

目标：增强审核、里程碑、客户交付和基础评分能力。

### v0.3：风控与投诉

目标：引入投诉、冻结、答辩、裁决和扣罚规则。

### v0.4：SKU 与常法服务

目标：支持标准化法律服务产品、动态客户表单和常法套餐。

### v1.0：私有化交付增强

目标：完善部署、运维、备份、审计、日志和系统参数能力。

- 管理员可以登录并创建用户。

- 客户可以通过验证码链接确认接收并评分。

- 财务可以确认结算。
- 关键操作写入审计日志。
