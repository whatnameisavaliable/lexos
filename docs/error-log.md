# Lexos 错误日志 Runbook

## 目标与边界

本文件用于 Lexos 私有化或本地化交付后的错误日志分级、脱敏和异常处置。错误日志记录系统异常、API 失败、数据库/RLS 异常、Storage 异常、认证权限异常、运维脚本失败和部署平台异常。

当前第一版只提供错误分类、字段口径、脱敏规则、本地核对脚本和处置建议，不新增数据库表，不采集 Next.js/Vercel/Nginx 日志，不写入日志文件，不接入外部错误监控平台，也不开发真实短信、新手保护期、新兵引流池、证据矩阵或 AI 辅助功能。

## 快速使用

执行：

```bash
npm run error:log:check
```

该命令会读取 `.env.local`，输出错误日志核对清单。命令不会创建目录，不会写入文件，不会连接线上 Supabase，也不会上传外部日志平台。

可选环境变量：

```env
LEXOS_ERROR_LOG_DESTINATION=server-runtime-log
LEXOS_ERROR_LOG_RETENTION_DAYS=180
LEXOS_ERROR_LOG_ALERT_CRITICAL=true
```

要求：

- 错误日志保留期最低不得低于 90 天。
- 错误日志目标不要位于 `public/`、`app/` 或其他静态托管目录。
- critical 级别错误应有人工告警或值班通知。
- 错误日志不得记录密码、验证码、token 明文、service role key、数据库连接串、Cookie 或客户案件材料原文。

## 错误分级

### critical

影响生产可用性、安全边界或数据完整性的错误。

示例：数据库连接失败、迁移失败、RLS 验证不通过、备份恢复失败、客户大屏或结算核心链路不可用。

处置：立即通知运维负责人，暂停升级或高风险操作，确认备份可用，保留错误摘要和版本信息。

### error

单个核心功能失败，但平台仍可部分运行。

示例：附件上传失败、结算导出失败、任务提交失败、真实 smoke 未完成闭环。

处置：记录 API 路径、业务对象 ID、用户角色、版本和错误摘要；必要时导出审计报表辅助定位。

### warning

风险信号或可恢复异常。

示例：失败登录激增、Preview health check 提示配置不完整、critical 告警未配置、日志责任人未指定。

处置：进入运维日志复核，跟踪是否升级为 incident。

### info

用于记录非错误的异常处置辅助信息，不应替代运维日志。

## 必记错误分类

- 应用运行时异常：Next.js route handler 未捕获异常、前端 API client 收到非预期响应。
- 业务 API 异常：创建任务、提交成果、客户确认、结算确认等接口失败。
- 数据库与 RLS 异常：迁移失败、连接失败、RLS 验证不通过。
- Storage 附件异常：上传、签名下载、Storage 备份或恢复失败。
- 认证与权限异常：失败登录异常、账号停用后访问、角色菜单不一致。
- 运维脚本与定时任务异常：备份、恢复、演练、真实 smoke、上线核对脚本失败。
- 外部平台与部署异常：Preview health check、反向代理、证书、域名或平台构建失败。

## 脱敏规则

必须脱敏或禁止记录：

- `password`、`token`、`secret`、`service_role`、`database_url`、`authorization`、`cookie` 等字段。
- 客户手机号完整明文。确需排查时只保留前三后四，例如 `138****0000`。
- 客户大屏 token、验证码、恢复确认口令和数据库连接串。
- 客户案件材料、交付附件正文和律师成果正文。

可以记录：

- 业务对象 ID、任务 ID、结算 ID、风控工单 ID。
- 已打码的数据库连接串。
- 错误摘要、HTTP 状态码、API 路径、版本号、commit。
- 操作角色，不记录用户密码。

## 与运维日志和审计日志的关系

- 错误日志记录异常本身和处置线索。
- 运维日志记录发布、迁移、备份、恢复、异常处置和复盘结论。
- 业务审计日志记录系统内用户操作。

发生生产异常时，错误日志提供事实线索，运维日志记录处置过程，业务审计日志用于核对用户操作影响。三者可以互相引用，但不要复制敏感明细。

## 当前限制

- 第一版不会自动拦截所有 API 异常。
- 第一版不会写入 JSONL、数据库表或外部监控平台。
- 第一版不会采集 Next.js server log、Vercel log 或 Nginx access log。
- 第一版不会提供错误趋势报表、告警路由或值班排班。
