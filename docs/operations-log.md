# Lexos 运维日志 Runbook

## 目标与边界

本文件用于 Lexos 私有化或本地化交付后的运维日志留存。运维日志记录“系统如何被部署、迁移、备份、恢复、验证和处置”，不同于业务审计日志；业务审计日志记录用户在系统内的业务操作。

当前第一版只提供日志制度、必记事件、证据要求和本地核对脚本，不新增数据库表，不写入日志文件，不上传外部日志平台，不接入错误告警，也不开发真实短信、新手保护期、新兵引流池、证据矩阵或 AI 辅助功能。

## 快速使用

执行：

```bash
npm run ops:log:check
```

该命令会读取 `.env.local`，输出运维日志核对清单。命令不会创建目录，不会写入文件，也不会连接线上 Supabase。

可选环境变量：

```env
LEXOS_OPERATIONS_LOG_DIR=ops-logs
LEXOS_OPERATIONS_LOG_OWNER=运维负责人
LEXOS_OPERATIONS_LOG_RETENTION_DAYS=365
LEXOS_OPERATIONS_LOG_REVIEW_INTERVAL_DAYS=30
```

要求：

- 保留期建议不少于 365 天，最低不得低于 180 天。
- 复核周期建议 30 天，最长不得超过 90 天。
- 运维日志目录不要放在 `public/`、`app/` 或其他会被静态托管的目录下。
- 运维日志不得记录密钥值、数据库连接串、用户密码、客户确认页 token 明文或客户案件材料原文。

## 必记事件

### 应用发布与回滚

必填字段：时间、版本/commit、环境、执行人、结果、回滚方案。

留存证据：构建输出、部署平台记录、发布审批记录。

禁止记录：密钥值、数据库连接串、客户资料明细。

### 数据库迁移

必填字段：时间、迁移文件、目标环境、执行人、执行结果。

留存证据：`supabase migration list` 输出、SQL Editor 执行记录、`npm run upgrade:check` 输出。

禁止记录：service role key、数据库密码、完整连接串。

### 数据库与 Storage 备份

必填字段：时间、备份类型、备份目录、对象数量/文件清单、责任人、校验结果。

留存证据：`manifest.json`、`storage-manifest.json`、`npm run backup:schedule` 输出、`npm run backup:task:check` 输出、`npm run backup:run:check` 输出。

禁止记录：客户文件原文、未打码数据库连接串、密钥值。

### 恢复演练与真实恢复

必填字段：时间、恢复来源、目标环境、执行人、确认口令已核验、验证结果。

留存证据：`npm run backup:rehearsal` 报告、恢复审批记录、RLS/smoke 结果。

禁止记录：恢复确认口令、数据库密码、客户敏感正文。

### 安全边界核对

必填字段：时间、核对范围、执行人、结果、遗留风险。

留存证据：`npm run private:check`、`npm run launch:check`、`npm run verify:rls` 输出。

禁止记录：真实 key、用户密码、客户确认页 token 明文。

### 真实闭环 smoke

必填字段：时间、环境、执行人、最终状态、测试数据处理口径。

留存证据：`npm run smoke:real` 输出摘要、验收库记录 ID、测试数据清理或保留说明。

禁止记录：客户手机号完整明文、客户确认页 token 明文、用户密码。

### 生产异常与处置

必填字段：时间、影响范围、发现人、处理人、处置动作、复盘结论。

留存证据：错误日志摘要、审计报表、处理工单。

禁止记录：客户案件材料原文、密钥值、未脱敏个人信息。

### 运维访问权限变更

必填字段：时间、账号/角色、变更原因、审批人、执行人、复核时间。

留存证据：账号变更记录、审批记录、复核清单。

禁止记录：初始密码、临时密码、私钥内容。

## 与业务审计日志的区别

- 运维日志：由运维或项目负责人记录，面向部署、迁移、备份、恢复、安全核对和事故处置。
- 业务审计日志：由系统自动写入 `audit_logs`，面向登录、创建用户、创建任务、客户确认、结算确认等业务操作。

两类日志可以互相引用，但不要互相替代。运维日志可以记录“已导出某段审计报表作为证据”，但不要复制大量客户业务明细。

## 当前限制

- 第一版不会自动创建 `ops-logs` 目录。
- 第一版不会写入 JSONL、CSV 或数据库日志表。
- 第一版不会采集 Next.js server log、Vercel log 或 Nginx access log。
- 第一版不会接入错误监控、性能监控或失败告警。
